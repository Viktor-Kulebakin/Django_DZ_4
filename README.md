# Корпоративный портал сотрудников (Django)

Веб-приложение для управления каталогом специалистов компании, их профессиональными навыками, рабочими местами и портфолио. 

## 🚀 Реализованный функционал 

- **Учёт стажа:** В модель сотрудника добавлено поле даты приёма на работу (`date_joined`).
- **Информативные карточки:** Реализован вывод ФИО, пола, номеров столов, навыков с уровнями освоения, а также автоматический расчёт стажа в днях.
- **Главная страница:** Отображает общее количество сотрудников в БД и карточки 4-х последних нанятых специалистов.
- **Пагинация:** На странице каталога настроен постраничный вывод сотрудников (по 10 человек на страницу).
- **Разделение галереи:** На подробной странице первое изображение выводится как заглавное фото, а остальные — в виде отдельной галереи портфолио.
- **Оптимизация (Prefetch Related):** Исключена проблема N+1 запросов за счёт оптимизированной предзагрузки связанных картинок и навыков во всех ключевых Views.
- **Умный валидатор рассадки:** Написана жесткая бизнес-логика на уровне модели, запрещающая размещать тестировщиков (`qa`) и разработчиков (`backend`, `frontend`) за соседними столами (+/- 1 от номера стола).
- **Качество кода:** Код полностью соответствует стандартам **PEP8** и задокументирован в стиле *Google Style Docstrings*.

## 🧪 Тестирование

Для проверки валидатора соседних столов написаны автоматические юнит-тесты (проверяющие как успешные сценарии, так и блокировку запрещенных рассадок).

Запуск тестов:
```bash
python manage.py test
```

## 🛠 Инструкция по локальному запуску

### 1. Подготовка окружения
Убедитесь, что ваше виртуальное окружение создано и активировано:
```bash
# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

### 2. Установка зависимостей
Установите все необходимые библиотеки, включая Django и CKEditor:
```bash
pip install -r requirements.txt
```

### 3. Применение миграций и настройка БД
Создайте структуру таблиц в базе данных SQLite:
```bash
python manage.py makemigrations
python manage.py migrate
```

### 4. Создание администратора
Создайте суперпользователя для управления сотрудниками через панель администратора:
```bash
python manage.py createsuperuser
```

### 5. Запуск сервера разработки
Запустите локальный сервер:
```bash
python manage.py runserver
```
Портал будет доступен в браузере по адресу: `http://127.0.0`  
Панель администратора: `http://127.0.0admin/`

## 📁 Структура проекта (Основные файлы)
- `models.py` — Расширенная модель `EmployeeProfile` с переопределенным методом `save()`, принудительным вызовом `full_clean()` и логикой в `clean()`.
- `views.py` — Оптимизированные контроллеры страниц со срезами, пагинацией и расчётом стажа.
- `admin.py` — Настроенное отображение новых полей, блоки `fieldsets` и фильтры.
- `tests.py` — Тест-кейсы для валидации бизнес-логики.
- `templates/` — HTML-шаблоны с интеграцией медиа-файлов и выводом контекста.
